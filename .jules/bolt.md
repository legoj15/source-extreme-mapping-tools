## 2024-04-08 - [Optimized Python Lightmap Parsing] **Learning:** Python loops using `struct.unpack_from` per-luxel incur massive overhead for large byte arrays. Using `struct.iter_unpack` over byte array slices can skip Python loop overhead and speed up the parse phase immensely. **Action:** Prefer `struct.iter_unpack` when reading identically-structured elements in bulk.
## 2024-05-18 - [Optimized Iter Unpack for Sparse Data] **Learning:** When extracting sparse or interleaved fields from dense binary arrays, utilizing the "x" format character in `struct.iter_unpack` (e.g. `<HxxHxxHxxxxxx`) allows efficient skipping of unused bytes. **Action:** Construct format strings with "x" to push byte-skipping to C and keep list comprehensions completely flat.
