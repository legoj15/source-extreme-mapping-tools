## 2024-04-08 - [Optimized Python Lightmap Parsing] **Learning:** Python loops using `struct.unpack_from` per-luxel incur massive overhead for large byte arrays. Using `struct.iter_unpack` over byte array slices can skip Python loop overhead and speed up the parse phase immensely. **Action:** Prefer `struct.iter_unpack` when reading identically-structured elements in bulk.

## 2024-05-01 - Python struct iter_unpack Truncation **Learning:** Using `struct.iter_unpack` on variable-length binary data (like `LUMP_VISIBILITY` in `bsp_reader.py`) can throw a `struct.error` if the sliced data length is not exactly divisible by the structure format size. **Action:** Always calculate the maximum safe slice boundary explicitly using integer division (e.g., `((len(data) - header_size) // struct_size) * struct_size`) to prevent failures on malformed or truncated files.
