// bspwalk game profiles (docs/bsp_walker_rebuild.md, "Game profile").
// Read by bspwalk.exe from its own directory. -profile <name> picks one; without it the
// profile named like the -game directory (or listing it in "gamedirs") is used, else hl2.
//
// Units are Hammer units and seconds. Omitted keys: crouch_lift = stand_height - crouch_height,
// max_air_speed = 2 x max_ground_speed, others take the hl2 value (eye_dead, a dead player's view
// height above the floor: VEC_DEAD_VIEWHEIGHT, 14 in g_DefaultViewVectors).
// reach_margin over-estimates speeds on purpose (it hedges constant error only); max_air_speed is
// the bhop / air-strafe ceiling the arc speeds run up to. air_jumps: extra jumps in the air (0 or 1).
// arc_max_drop: arcs are tried out to the XY reach of a fall this deep below the launch height
// (deeper targets still get arcs inside that reach). hl2 and episodic use the fatal fall: CHalfLife2
// is CSingleplayRules (game/shared/hl2/hl2_gamerules.h:31), whose FlPlayerFallDamage
// (game/shared/singleplay_gamerules.cpp:289-290) gives 100 damage at the HL2_DLL
// PLAYER_FATAL_FALL_SPEED 922.5 (game/shared/shareddefs.h:370); height v^2 / 2g plus the jump apex
// (a little generous, which only adds pairs). hl2mp falls are not fatal: CHL2MPRules is
// CMultiplayRules, whose FlPlayerFallDamage (game/shared/multiplay_gamerules.cpp:619-631) gives a
// fixed 10 damage under the default mp_falldamage 0 (game/server/game.cpp:34).
//
// hl2, episodic and hl2mp come from the Source SDK 2013 code (HL2_DLL builds):
//   hull and eyes game/shared/gamerules.cpp g_DefaultViewVectors; sv_stepsize 18 movevars_shared.cpp;
//   gravity 600 movevars_shared.cpp DEFAULT_GRAVITY_STRING; jump 160 gamemovement.cpp CheckJumpButton;
//   speeds hl2_normspeed 190 / hl2_sprintspeed 320 hl2_player.cpp (hl2mp uses the same defines).
// cstrike and tf are not in the SDK 2013 tree: well-known values, unverified against game code.
// Checked status (#16): hl2 and episodic are fixture-tested; hl2mp is SDK-sourced but untested;
// cstrike and tf are unverified until each has run on a real map.
